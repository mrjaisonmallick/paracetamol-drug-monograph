# 
Paracetamol | Pharmaceutical Drug Monograph

An interactive, evidence-referenced pharmaceutical drug monograph on Paracetamol (Acetaminophen), developed as an educational resource for pharmacy students and healthcare learners.

Overview

This project presents comprehensive pharmaceutical and clinical information about paracetamol through a structured, interactive web interface.

It aims to make drug-related information more accessible while maintaining scientific accuracy, transparent sourcing and clear distinctions between established evidence and proposed mechanisms.

Features

- Drug Overview: Classification, chemical properties and pharmacological profile.
- Mechanism of Action: Interactive exploration of analgesic, antipyretic and hepatotoxicity pathways.
- Therapeutic Indications: Classification of approved, off-label and investigational uses.
- Dosage and Administration: Reference-based dosing information across different patient groups and formulations.
- Pharmacokinetics: Absorption, distribution, metabolism and excretion (ADME).
- Safety Profile: Adverse reactions, contraindications and precautions.
- Toxicology: Overdose mechanisms, risk factors and management principles.
- Drug Interactions: Searchable interaction information with evidence-quality classifications.
- India-Specific Context: Essential medicine status, available formulations and relevant Indian pharmaceutical information.
- References: Linked scientific literature, prescribing information and regulatory sources.

Technology Stack

- CSS3

- Responsive web design
- Interactive data visualisation
